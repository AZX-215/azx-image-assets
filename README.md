## Overview

This repository provides a centralized location for storing, organizing, and hosting image assets used throughout AZX projects.

Assets may include original, edited, converted, resized, optimized, or project-specific images intended for use in:

- GitHub repositories and README files
- Project documentation
- Websites and applications
- Logos and branding
- Screenshots and reference material
- Development and testing resources

## Supported Formats

| Format | Typical Use |
|:------:|-------------|
| `RAW` | Original or minimally processed source images |
| `PNG` | Logos, graphics, transparency, and lossless assets |
| `JPG` / `JPEG` | Photographs, screenshots, and compressed images |
